Lab CA certificate

Download the CA certificate used by *.lab.internal and install it on your device to trust the internal TLS certificates.

Download lab-cluster-ca.crt

iPhone / iPad

  1. Open lab-cluster-ca.crt in Safari.
  2. Install the downloaded profile in Settings -> General -> VPN & Device Management.
  3. Then enable trust in Settings -> General -> About -> Certificate Trust Settings.
  4. Reconnect NetBird and open https://dashboard.lab.internal.

Mac

  1. Download lab-cluster-ca.crt.
  2. Open it in Keychain Access and add it to the System keychain.
  3. Set the certificate trust to Always Trust.
